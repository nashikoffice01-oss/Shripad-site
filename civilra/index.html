QUESTIONS FROM ENGINEERS

Frequently asked questions

Real questions from engineers evaluating Civil RA for infrastructure, railway, highway and EPC work.

Does it support the way I prepare a professional tender rate analysis — especially for infrastructure, railway, highway or EPC works?

Yes. Earthwork, RCC, roads, railways, tunnels, jetties, barrages and distribution network items all follow the same Material + Labour + Machinery + Diesel + Productivity + Lead + Overhead + Profit structure as any other BOQ item — it's built around how tender-grade RA is actually prepared on infrastructure projects.

Can one project have multiple BOQ revisions?

Yes. A revised BOQ can be brought into the same project without losing the rate analysis work already done on it.

Machinery — owned or hired? Which basis does the tool work on?

Both. You can cost machinery either way, depending on how you're actually sourcing it on your project.

Can wastage be defined resource-wise, rather than only item-wise?

Yes — wastage is built into the consumption and productivity figures you enter per resource (for example, a 1.05 consumption factor, or a 0.95 productivity factor), so it's already resource-specific rather than a single item-level percentage.

Royalty and statutory charges — can these be separate cost components rather than embedded in the material rate?

Yes. These can be handled as a separate component within the rate analysis, as their own BOQ item, or as part of the preliminary (prelim) cost calculation — whichever matches how your project treats them.

Composite RA — can one rate analysis use another RA as a component?

Yes. You can build a "mini RA" purely to calculate a resource's own rate, then use that resource rate inside other analyses — so a rate can be composed from other rates.

Machinery — can it calculate fuel, operator, depreciation, maintenance and hiring cost?

Fuel is linked directly to machine consumption within the RA. Operator cost can be included either within the machine's hire/rent rate, or entered as a separate individual labour cost — whichever matches how you actually contract it.

Excel — are formulas and resource relationships preserved during export and re-import?

Yes. Exported files keep live Excel formulas and resource relationships intact. On re-import, only the items you've actually changed are updated — nothing else is touched.

Can current rates be compared with previous projects or SSR?

Yes. You can check a rate against your own past projects or against SSR (Schedule of Rates) before finalising your quote.

Can you demonstrate an actual infrastructure item — earthwork, RCC, road, railway, tunnel, jetty, barrage or distribution network — with Material + Labour + Machinery + Diesel + Productivity + Lead + OH + Profit?

Yes — a sample project backup with worked examples across these categories is included with every license, so you can see the full breakdown on real infrastructure items from day one.
