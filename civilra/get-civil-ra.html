How to start (2 minutes)

  1. Find the file — Civil_RA.html in your Downloads folder. Move it to a folder you will remember, such as Documents.
  2. Open it with Chrome or Edge — double-click the file, or right-click → Open with → Chrome / Edge. It works fully offline.
  3. Register your name when asked, then upload your BOQ Excel file to create your first project.
  4. Keep the file safe — your projects are stored in that browser on that computer. Use Export backup regularly.
